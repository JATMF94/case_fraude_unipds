# Análise de Fraude — Diagnóstico e Cenário Atual

Este repositório reúne o estudo desenvolvido a partir dos dados fornecidos para a empresa, com a estruturação de uma base consolidada de **150.200 transações** para diagnosticar o cenário atual de fraude, avaliar a performance dos modelos e direcionar planos de ação.

Na análise, avaliamos:
* **Mercado de atuação da empresa** (comportamento e concentração de fraude por país)
* **Canal de venda** (distribuição das taxas de fraude entre canais e parceiros)
* **Categorias de produtos** (concentração de perdas, taxa de fraude e ticket médio por categoria)
* **Resultado do atual motor de fraude** (evolução entre versões dos modelos e comportamento dos scores)
